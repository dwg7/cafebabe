1. **弱いのは、テーマをまたぐ問い。** 唯一の partial は T01 で、必要な知見は開いたファイルの中にあったのに、

   別の節にあるためです。メインツリーの `/themes/` の入口と、またぐテストが要る、という計画の見立てと合います。
2. **最新の結論が、長い節の末尾の「訂正・追記」にある。** 回答者は、T02 と T03 で、見出しと本文だけ読むと
   古い結論になると指摘しました。追記で積む方式の帰結です。miso の形では、オブジェクトの冒頭の状態と
   要約を最新に保ち、経緯を `## 訂正・追記` に残す、という分け方で直せます(段階 1 で確かめる)。
3. **索引は、テーマからしか引けない。** プロジェクト名(snow-hokkaido、miso、dorayaki)や、横断の語(Pages)
   からは、`README.md` で辿れず、全文検索に頼りました。
